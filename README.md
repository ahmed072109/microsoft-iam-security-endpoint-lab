# Microsoft IAM, Security & Endpoint Lab

A hands-on Microsoft cloud security lab focused on Identity and Access Management (IAM), endpoint management, and security using Microsoft Entra ID, Microsoft Intune and Microsoft Defender.

## 🎯 Objectives

This project documents my practical experience designing and implementing Microsoft identity, endpoint and security solutions in a simulated enterprise environment.

The lab focuses on:

- Microsoft Entra ID
- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Least Privilege Access
- Multi-Factor Authentication (MFA)
- Self-Service Password Reset (SSPR)
- Conditional Access
- Privileged Identity Management (PIM)
- Identity Governance
- Microsoft Intune
- Windows Endpoint Management
- Device Compliance
- Endpoint Security
- Microsoft Defender
- Zero Trust Security

## 🏢 Lab Scenario

The environment simulates a fictional organisation called **Falcon Tech** with employees across:

- IT
- Finance
- Human Resources
- Sales
- Management

The environment will be used to implement and test identity lifecycle management, access controls, endpoint management and security policies.
